# NinjaAdventure Godot starter

A browser-ready Godot project configured for Pompeii's `godot` runtime target.

Pompeii discovers the starter metadata and deterministic preview stack from
`.pompeii/metadata.json` and `.pompeii/preview.yml`.

Run `pompeii-godot doctor`, `pompeii-godot test`, `pompeii-godot asset-audit`,
and `pompeii-godot export-web` before publishing changes. Arrow keys and a
gamepad move the player.
